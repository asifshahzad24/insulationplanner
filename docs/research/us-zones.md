# US ZIP (ZCTA) to 2021 IECC climate zone

Generated by `scripts/build.mjs` from the inputs fetched by `scripts/fetch.mjs`. Re-running both scripts reproduces these files byte for byte (no timestamps; all keys sorted). The scripts need Node.js 18 or later and have no dependencies:

```
node scripts/fetch.mjs       # download sources into raw/ (data only, never executed)
node scripts/build.mjs       # write out/
node scripts/verify-pdf.mjs  # optional: cross-check the shapefile against the PNNL report table
node scripts/spotcheck.mjs   # look up the test ZIPs the way the website will; checks file integrity
```

Zone strings are `<number><moisture>`: `1A`-`6C`, with no letter for zones `7` and `8` (the IECC assigns no moisture regime there). No county in this dataset is in zone 0. In `states.json`, zones are ordered by how many of that state's counties use them (ties broken alphabetically).

Lookup for a ZIP: fetch `zip3/<first 3 digits>.json` and read the 5-digit key. A missing file or missing key means the ZIP is not a 2020 ZCTA (PO-box-only and single-business ZIPs usually are not) or is in a US territory; see Caveats.

## Sources

1. **County to 2021 IECC climate zone.** Pacific Northwest National Laboratory (PNNL) for the US DOE Building America program: *Guide to Determining Climate Zone by County: Building America and IECC 2021 Updates*, PNNL-33270, September 2022 (Antonopoulos, Gilbride, Margiotta, Cragin, Kaltreider). The data comes from its companion GIS file, `ClimateZones.dbf` inside https://basc.pnnl.gov/sites/default/files/ClimateZoneDataFiles.zip, using fields `IECC21` and `Moisture21`. The report PDF (https://www.pnnl.gov/main/publications/external/technical_reports/PNNL-33270.pdf) was used to correct gaps in the shapefile. These are the climate zones of the 2021 IECC, Table R301.1 / C301.1, which is based on ASHRAE 169-2013. The 2024 IECC kept the same map. The file also carries the pre-2021 assignments (`IECC15`). 373 of its counties changed zone in 2021, and this dataset uses the 2021 assignments.
2. **ZCTA to county.** US Census Bureau, 2020 ZCTA to 2020 County Relationship File: https://www2.census.gov/geo/docs/maps-data/data/rel2020/zcta520/tab20_zcta520_county20_natl.txt
3. **County names and FIPS codes.** US Census Bureau, 2020 FIPS codes: https://www2.census.gov/geo/docs/reference/codes2020/national_county2020.txt

## Method

1. Read `ClimateZones.dbf` (3220 rows, keyed by `G` + 5-digit county FIPS). Zone = `IECC21` + `Moisture21`. Every value is checked against `^([0-6][ABC]|[78])$`.
2. Apply corrections backed by the report table or a Census FIPS change:
   - `20101` set to `4A`. Lane County, KS: shapefile IECC21 = 5A (unchanged from pre-2021); the PNNL-33270 table explicitly marks a 2021 change "Cold -> Mixed-Humid, 5 -> 4, A" (neighbors Ness and Trego also moved 5A -> 4A).
   - `34021` set to `4A`. Mercer County, NJ: shapefile IECC21 = 5A (unchanged from pre-2021); the PNNL-33270 table explicitly marks a 2021 change "Cold -> Mixed-Humid, 5 -> 4, A". The report (Sept 2022) is newer than the shapefile (Aug 2022).
   - `51520` set to `4A`. Bristol city, VA: shapefile has zone 4 with a blank moisture regime; PNNL-33270 table lists "Bristol (city) ... 4 A".
   - `02158` set to `8`. Kusilvak Census Area (formerly Wade Hampton, FIPS 02270): zone is NaN in the shapefile; PNNL-33270 table lists "Wade Hampton (CA) ... 8" (unchanged in 2021).
   - `02063` set to `7`. Chugach Census Area, split from Valdez-Cordova (02261) in 2019; inherits Valdez-Cordova zone.
   - `02066` set to `7`. Copper River Census Area, split from Valdez-Cordova (02261) in 2019; inherits Valdez-Cordova zone.
   These corrections come from `scripts/verify-pdf.mjs`, which parses the county table in the PNNL-33270 PDF and compares it with the shapefile. It matched 3,131 of the 3,142 shapefile rows for the 50 states and DC. 3,127 agree, and the 4 disagreements are the first four corrections above. The 11 unmatched rows are text-extraction artifacts at page breaks.
3. Join to the 2020 Census county list by FIPS code. Names (for example "Cook County", "Bristol city", "Anchorage Municipality") come from Census. The build fails if any county in the 50 states or DC lacks a zone. PNNL rows with no 2020 Census county (unused): `02261` Valdez-Cordova.
4. For each ZCTA in the relationship file (rows with a blank ZCTA are skipped; 46,960 ZCTA-county rows), pick the county with the largest `AREALAND_PART`. Ties go to the larger `AREAWATER_PART`, then the lower FIPS. The ZCTA gets that county's zone.
5. Group by the first 3 digits and write compact JSON with sorted keys.

## Caveats

- **ZCTAs are not ZIP codes.** ZCTAs approximate the areas of residential and delivery ZIP codes. Many PO-box-only and single-organization ZIPs have no ZCTA, so they are absent here. Among the spot checks: 85001 is not a 2020 ZCTA. 33101 (a Miami PO-box ZIP) does exist as a 2020 ZCTA. A UI should say "ZIP not found, try a nearby residential ZIP" or ask for the county.
- **County granularity.** The IECC assigns zones by county, and a ZCTA takes the zone of the county containing most of its land. 365 ZCTAs have 25% or more of their land in a county with a different zone. Examples: 03276: 5A (Merrimack County, NH); 28% of land in other-zone counties; 03602: 5A (Cheshire County, NH); 37% of land in other-zone counties; 04424: 6A (Washington County, ME); 46% of land in other-zone counties; 04451: 7 (Aroostook County, ME); 48% of land in other-zone counties; 04459: 7 (Aroostook County, ME); 49% of land in other-zone counties. The zone that legally applies can also differ where a state or city has amended its code; Ketchikan, AK is one example.
- **US territories.** The PNNL data covers only the 50 states and DC. Its Puerto Rico rows have no zone, and it has no rows for the other territories. The 149 territory ZCTAs (Puerto Rico 132, Guam 7, US Virgin Islands 6, Northern Mariana Islands 3, American Samoa 1) are therefore left out rather than guessed. The IECC table may list territories, but it could not be checked because it is paywalled.
- **Mercer County, NJ and Lane County, KS.** PNNL's own files disagree on these two counties: the shapefile says 5A and the report table says 4A. This build follows the report, which explicitly marks the 2021 change. The ICC code text could not be checked directly because it is paywalled. Together they cover 24 ZCTAs. To revert, delete those two entries from `OVERRIDES` in `scripts/build.mjs`.
- **Snapshot dates.** County FIPS codes are 2020 Census codes. Connecticut is still the 8 historical counties, which matches PNNL. The 2022 Connecticut planning regions are not used.
